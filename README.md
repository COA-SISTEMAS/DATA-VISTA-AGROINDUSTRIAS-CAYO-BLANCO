# DATA VISTA

Plataforma web para análisis estadístico y visualización de datos de campo.

La versión inicial incluye importación de archivos Excel/CSV, exploración de datos, revisión de calidad, estadística descriptiva, análisis de variables categóricas, correlaciones, agrupaciones y exportación de resultados.

## Inicio

Abre `index.html` en un navegador moderno. No requiere instalación de servidor para las funciones locales.

## Estructura

- `index.html`: interfaz principal.
- `assets/css/styles.css`: estilos responsivos.
- `assets/js/app.js`: interacción de la aplicación.
- `modules/analyzer.js`: funciones de análisis.
- `docs/METODOLOGIA.md`: metodología y alcance.

## Estado

Versión inicial en desarrollo. Las conexiones externas y exportaciones deben validarse con fuentes y navegadores reales antes de un despliegue de producción.
